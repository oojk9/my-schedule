# 일정·근무 수첩 (v1.2.0)

약속·예약 같은 **일정**, 카드 결제일·적금 자동이체처럼 **매달 돌아오는 루틴**, 일용직 근무처럼 **한 달에 몇 번 했는지 세는 일**,
단계가 있는 **프로젝트 진행 상황**을 한 달력에서 관리하는 개인 수첩입니다.

- 갤럭시에 **앱으로 설치**하면 주소창 없이 다른 앱처럼 아이콘으로 열려요.
- **매달 루틴**은 한 번만 적어 두면 매달 새로 적지 않아도 달력과 오늘 화면에 저절로 나타나요.
- **PC와 연동**: 같은 계정으로 로그인한 PC·폰에서 같은 기록이 보이고, 한쪽에서 고치면 다른 쪽에도 바로 반영돼요.
- 인터넷이 끊겨도 열리고 기록할 수 있어요. 연결되면 자동으로 올라가요.

## 파일 구성 (9개)

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면 + 디자인 + 동작) |
| `config.js` | **PC·폰 연동 설정** — 3단계에서 Firebase 설정을 한 번 붙여 넣는 파일 |
| `sw.js` | 인터넷 없이도 앱이 열리게 해 주는 파일 |
| `manifest.webmanifest` | 앱 이름·아이콘 같은 "설치 정보" |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `firestore-rules.txt` | Firebase 보안 규칙 (3단계에서 복사해 붙여 넣기) |
| `README.md` | 이 설명서 |

## 전체 흐름 (처음 한 번, 30분 정도 · PC에서 하는 게 편해요)

1. **GitHub에 올리기** → 나만의 앱 주소가 생겨요 (10분)
2. **폰에 설치** → 이때부터 바로 쓸 수 있어요 (이 기기에만 저장)
3. **Firebase 만들기** → PC·폰 연동이 켜져요 (15분, 무료)
4. **PC에서도 열기·설치**

## 1단계. GitHub에 올리기

자산관리 앱 때 만든 GitHub 계정을 그대로 쓰면 돼요. (없다면 <https://github.com> → **Sign up**)

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `my-schedule` → **Public** 선택 → **Create repository**
   (무료 계정은 Public이어야 앱 주소를 만들 수 있어요. 공개되는 건 앱 코드뿐이고, 기록은 공개되지 않아요)
3. **uploading an existing file** 클릭 → 압축 푼 `my-schedule` 폴더 **안의 파일 9개**를 모두 끌어다 놓기 → **Commit changes**
4. 저장소 위쪽 **Settings** → 왼쪽 **Pages** → Source: **Deploy from a branch** → Branch: **main**, **/ (root)** → **Save**
5. 1~2분 뒤 새로 고침하면 주소가 나와요. 예) `https://아이디.github.io/my-schedule/`

## 2단계. 갤럭시에 설치

1. 폰에서 **크롬(Chrome)** 을 열고 위 주소로 접속
   (카톡 안에서 링크를 바로 열지 말고, 주소를 복사해서 **크롬 주소창**에 붙여 넣으세요)
2. 화면 위쪽 **[앱 설치]** 버튼을 누르거나, 크롬 오른쪽 위 **⋮ → 앱 설치**(또는 **홈 화면에 추가 → 설치**)
   - '바로가기 만들기'가 아니라 **설치**를 고르세요.
3. 홈 화면(또는 앱스 화면)에 생긴 **일정수첩** 아이콘으로 열면 끝!
   - 아이콘을 **길게 누르면** '새 일정', '근무 기록', '달력' 바로가기가 나와요.

> 3단계 전에는 **이 기기에만** 저장돼요. 지금 적은 기록은 나중에 로그인하면 계정으로 옮길 수 있어요.

## 3단계. PC·폰 연동 켜기 (Firebase, 무료)

Firebase는 구글이 만든 무료 저장 서비스예요. 기록이 **내 Firebase 계정**에 저장되고,
같은 계정으로 로그인한 기기끼리 자동으로 맞춰져요. 화면 메뉴 이름이 조금 다르면 위쪽 **검색창**에 이름을 입력해서 찾으세요.

### 3-1. 프로젝트 만들기
1. PC에서 <https://console.firebase.google.com> 접속 → 구글 계정으로 로그인
2. **프로젝트 만들기**(새 Firebase 프로젝트 만들기) → 이름 `my-schedule` → 계속
3. Gemini·Google 애널리틱스는 **꺼도 돼요** → **프로젝트 만들기** → 계속

### 3-2. 로그인 방식 켜기 (Authentication)
1. 왼쪽 메뉴에서 **Authentication**(인증)을 찾아 누르기 → **시작하기**
2. **로그인 방법**(Sign-in method) 탭 → **이메일/비밀번호** → 첫 번째 스위치 **사용 설정** → **저장**
   (그 아래 '이메일 링크'는 꺼 둔 채로)

### 3-3. 데이터베이스 만들기 (Firestore)
1. 왼쪽 메뉴에서 **Firestore** (Firestore Database)를 찾아 누르기 → **데이터베이스 만들기**
2. 버전을 고르라고 나오면 **Standard**, 데이터베이스 ID는 그대로 **(default)**
3. 위치: **asia-northeast3 (Seoul)** → 다음
4. **프로덕션 모드**(Production mode) → **만들기**

### 3-4. 보안 규칙 붙여 넣기
1. Firestore 화면 위쪽 **규칙**(Rules) 탭
2. 원래 있던 내용을 **모두 지우고**, `firestore-rules.txt` 파일 내용을 그대로 붙여 넣기 → **게시**(Publish)
   → 로그인한 본인만 자기 기록을 읽고 쓸 수 있게 하는 규칙이에요.

### 3-5. 앱 등록하고 설정값 복사
1. 왼쪽 위 **프로젝트 개요** 옆 톱니바퀴 ⚙ → **프로젝트 설정**
2. 아래쪽 **내 앱**에서 웹 아이콘 **`</>`** → 앱 닉네임 `일정수첩` → (Firebase 호스팅은 체크하지 않음) → **앱 등록**
3. 화면에 나오는 코드에서 `const firebaseConfig = { ... };` 부분을 복사
   - 앞뒤 줄(`import ...` 등)이 같이 복사돼도 괜찮아요.
   - 나중에 다시 보려면: 프로젝트 설정 → 내 앱 → **SDK 설정 및 구성**

### 3-6. config.js에 붙여 넣기
- **방법 A (GitHub에서 바로)**: 저장소에서 `config.js` 클릭 → 오른쪽 위 연필 ✏️ → `여기에 붙여 넣기` 줄을 지우고 그 자리에 붙여 넣기 → **Commit changes**
- **방법 B**: PC에서 `config.js`를 메모장으로 열어 같은 자리에 붙여 넣고 저장 → GitHub 저장소 **Add file → Upload files**로 덮어쓰기
- 이 설정값은 비밀번호가 아니라 '어느 Firebase 프로젝트인지' 알려 주는 주소 같은 거라 공개돼도 괜찮아요.

### 3-7. 로그인
1. 몇 분 뒤 폰에서 앱을 **완전히 닫았다가 다시 열기** → 로그인 화면이 나와요
   (이미 '이 기기에서만' 쓰고 있었다면: ⚙ 설정 → **로그인하고 연동 켜기**)
2. 처음이면 **처음이에요 · 계정 만들기** → 이메일 + 비밀번호(6자 이상) → **계정 만들고 시작하기**
   - 이 앱에서만 쓰는 계정이에요. 네이버·구글 비밀번호와 다르게 정해도 돼요.
3. 이 기기에 적어 둔 기록이 있으면 **계정으로 옮기기** 안내가 나와요 → 누르면 끝

## 4단계. PC에서 쓰기

1. PC 크롬(또는 엣지)에서 같은 주소를 열고 **같은 이메일·비밀번호로 로그인**
2. 주소창 오른쪽의 **설치 아이콘**(모니터에 화살표) → **설치** → 시작 메뉴·바탕화면에 앱이 생겨요
3. 이제 폰에서 기록하면 PC에도 몇 초 안에 나타나요. 반대도 마찬가지예요.

## 사용법

- **오늘**: 오늘 일정, 밀린 할 일, 앞으로 45일 일정, 이번 달 루틴, 이번 달 횟수, 진행 중인 프로젝트
- **달력**: 공휴일(빨간색), 일정, ↻ 매달 루틴, 근무한 날 **도장**, 프로젝트 단계·목표일. 위쪽 버튼으로 보이는 항목을 골라요
- **루틴**: 매달 돌아오는 일만 모아 보는 화면 (아래 '매달 루틴 쓰는 법')
- **기록**: 항목별 이번 달 횟수·금액·목표, 날짜별 도장판, 최근 6개월 막대
  - 일한 날 **[오늘 1회 기록]** 한 번이면 끝. 다른 날은 도장판의 날짜를 누르세요
  - 항목 **설정**에서 일당(1회 금액)을 넣으면 한 달 금액이 계산돼요. 반나절까지 세려면 단위를 **공수**로
- **프로젝트**: **시작하기** → 단계 체크 → 진행률(%)이 올라가요. 보류·완료, 진행 메모, 연결된 일정
  - **순서 바꾸기**·**묶음 접기**는 아래 '프로젝트 순서 바꾸기 · 접어 두기'
- 오른쪽 아래 **+**: 일정 / 매달 루틴 / 근무·횟수 기록 / 프로젝트 추가
- 폰의 **뒤로 가기**: 열린 입력 창을 닫고, 이전 화면으로 돌아가요
- ⚙ **설정**: 연동 상태, 앱 설치, 백업, 버전

### 매달 루틴 쓰는 법

1. 아래 **루틴** 탭 → **새 루틴** (처음엔 '카드 결제일', '적금 자동이체', '월급날', '관리비 납부' 버튼으로 빠르게 시작할 수 있어요)
2. 이름, 종류(결제·납부 / 저축·적금 / 들어오는 돈 / 기타), **매달 며칠**(1~31일 또는 **말일**), 금액을 적고 저장
3. 이제 매달 그 날짜에 달력·오늘 화면·다가오는 일정에 ↻ 표시로 나타나요. 새로 적을 필요가 없어요.

- **주말·공휴일이면**: '다음 평일로 미루기'(카드 결제·자동이체), '앞 평일로 당기기'(월급), '그 날 그대로' 중에 골라요.
  예) 매달 3일 자동이체인데 3일이 토요일·개천절이고 5일이 대체공휴일이면 → **6일(화)**로 표시돼요. (2026–2027년 공휴일 반영)
- **31일**처럼 그 달에 없는 날은 그 달 **말일**로 보여요.
- **확인 체크**: 결제됐는지 확인했으면 체크해 두세요. 달마다 따로 체크돼서, 다음 달엔 다시 빈 칸이에요.
- **루틴 화면 위쪽**: 그 달에 나갈 돈(결제·납부 + 저축) 합계, 아직 안 나간 돈, 들어오는 돈, 확인한 개수
- **끝나는 달**: 적금 만기처럼 끝나는 달을 정하면 그 뒤로는 안 나와요.
- **잠시 멈춤**: 루틴을 눌러 '매달 보여 주기'를 끄면 멈춰요. 지우지 않아도 돼요.
- 일정을 추가할 때 **'매달 이 날짜에 반복'**을 체크하면 루틴으로 저장돼요.

### 프로젝트 순서 바꾸기 · 접어 두기

**순서 바꾸기** — 만든 순서와 상관없이 원하는 자리로 옮길 수 있어요.
1. **프로젝트** 탭 위쪽 **⇅ 순서 바꾸기** (같은 묶음에 프로젝트가 2개 이상일 때 보여요)
2. 줄 왼쪽 **손잡이**(점 6개)를 잡고 위아래로 끌거나, 오른쪽 **위·아래 화살표 버튼**으로 한 칸씩 옮기기
   - 목록이 길면 손가락을 화면 위·아래 끝으로 가져가세요. 저절로 스크롤돼요.
   - 진행 중 · 준비 중 · 보류 · 완료 **묶음 안에서만** 움직여요. 묶음을 바꾸려면 프로젝트를 열어 상태를 바꾸세요.
3. 다 옮겼으면 **완료** (폰의 **뒤로 가기**를 눌러도 돼요)

- 옮기는 즉시 저장되고, 연동을 켰다면 PC·폰에서 같은 순서로 보여요. **오늘** 화면의 '진행 중인 프로젝트'도 같은 순서예요.
- 새로 만든 프로젝트, 상태가 바뀐 프로젝트(예: 준비 → 시작)는 그 묶음의 **맨 아래**에 들어가요.

**접어 두기** — 진행 중 · 준비 중 · 보류 · 완료 묶음 이름(예: **진행 중 3**)을 누르면 접히고, 다시 누르면 펼쳐져요.
- 접힌 묶음은 '**› 준비 중 2 · 접힘**'처럼 개수만 보여요.
- 앱을 껐다 켜도 접어 둔 그대로예요. 접기는 **기기마다 따로** 기억해요(폰에서 접어도 PC는 그대로).

## 데이터와 백업

- **연동을 켜면** 기록은 내 Firebase 계정에 저장돼요. 폰을 바꿔도 로그인만 하면 그대로예요.
- **연동을 안 켜면** 이 기기의 크롬 저장소에만 있어요. 크롬 데이터 삭제·폰 교체 때 사라질 수 있으니 백업해 두세요.
- ⚙ 설정 → **백업 파일 저장**(다운로드 폴더) / **보내기**(카톡·드라이브) / **백업 불러오기**
  - 불러오기는 지금 기록에 **더해져요**(같은 항목은 백업 내용으로 바뀌어요).
- 무료 한도는 하루 읽기 5만 번·쓰기 2만 번이라 개인 수첩으로는 넉넉해요.
- 같은 주소(`아이디.github.io`)의 **내 자산관리** 앱과 저장 공간이 따로라 서로 영향을 주지 않아요.

## 문제가 생겼을 때

| 화면에 나온 말 | 할 일 |
|---|---|
| 기록을 불러올 권한이 없어요 | 3-4단계: 규칙을 붙여 넣고 **게시**를 눌렀는지 확인 |
| Firestore 데이터베이스를 찾지 못했어요 | 3-3단계: 데이터베이스 만들기 |
| 이메일/비밀번호 로그인이 꺼져 있어요 · Authentication을 아직 시작하지 않았어요 | 3-2단계 |
| config.js의 설정값이 맞지 않아요 · 설정값을 읽지 못했어요 | 3-5단계에서 다시 복사해 3-6단계대로 붙여 넣기 |
| 로그인 화면이 안 나오고 설정에 '준비 전' | config.js가 아직 반영 전이에요. 몇 분 뒤 앱을 완전히 닫았다가 다시 열기 |
| 비밀번호를 잊었어요 | 로그인 화면의 **비밀번호를 잊었어요** → 메일함(스팸함 포함) 확인 |
| 연동 기능을 불러오지 못했어요 | 처음 한 번은 인터넷이 필요해요. 연결 후 **다시 시도** |

## 앱을 고쳤을 때 (업데이트)

**아직 GitHub에 올리기 전이라면**: 새 zip의 파일 9개를 1단계대로 처음부터 올리면 돼요.

**이미 올려서 쓰는 중이라면 (v1.1.0 → v1.2.0)**: 바뀐 파일만 올리면 돼요.
1. GitHub 저장소 → **Add file → Upload files** → 업데이트 zip의 `index.html`, `sw.js`, `README.md` **3개**를 끌어다 놓기 → **Commit changes**
   - 같은 이름의 파일은 새 파일로 바뀌어요. 나머지 파일(아이콘·`manifest.webmanifest`·`firestore-rules.txt`)은 그대로 두세요.
   - ⚠️ **`config.js`는 건드리지 마세요.** 연동 설정이 들어 있는 파일이라, 다른 파일로 덮어쓰면 연동이 꺼져요.

2. 1~10분 뒤 앱을 **완전히 닫았다가 다시 열기**. '새 버전이 준비됐어요' 알림이 뜨면 **새로 고침**을 누르세요.
